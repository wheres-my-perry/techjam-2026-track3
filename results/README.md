# Curated results

Only reproducible, report-relevant evidence is tracked here:

- `final/`: promoted active-main evidence and environment manifest.
- `timeline/`: same-host historical checkpoint sweep and drift controls.
- `experiments/`: retained evidence for unpromoted candidates.
- `archive/`: superseded or cross-host evidence kept for auditability.

Ad-hoc benchmark, profiler, trace, temporary, and remote-capture output belongs
under the gitignored `runs/` directory instead.
